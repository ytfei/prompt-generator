# 提示词工坊（Prompt Studio）产品需求文档

> 版本：v0.2（草案） ｜ 日期：2026-11-19 ｜ 状态：待评审
> 配套交付：`prototype/index.html` 静态原型（本次评审用）
> v0.2 变更：新增「图生图」模式（Tab 框架、场景系统、修改模板、Agent 生成逻辑），原功能归入「文生图」Tab
> v0.2.1 变更：图生图创意方向由 4 个扩充至 11 + 默认（见 M8）

---

## 1. 背景与痛点

用户日常运营公众号，需要高频为文章生成配图。当前直接在「即梦」等文生图工具上手写提示词，存在以下问题：

1. **考虑维度不全**：文生图涉及风格、光线、色调、构图、情绪、质感等大量维度，手写时容易遗漏，导致出图"差点意思"。
2. **表达不专业**：不熟悉生图模型偏好的提示词写法，描述口语化、不成体系，出图效果不稳定。
3. **重复劳动**：每次配图都从零写提示词，缺少可复用的配置与模板。

## 2. 产品定位

**一站式生图提示词工作台**，提供两种模式（顶部 Tab 切换）：

- **文生图**：「参数化选项 + 主题描述 + AI Agent 优化」三步，从零生成一条结构完整的高质量提示词。
- **图生图**：「图片内容描述 + 修改/创意意向 + AI Agent 优化」，基于已有图片产出修改、延展、风格化提示词，配合即梦的图生图能力使用。

**本服务不直接生图**。生图执行仍由用户在即梦完成（图生图需用户在即梦上传原图），本产品只负责"产出靠谱的提示词"。**图生图模式同样不需要上传图片**：用户用文字描述图片内容即可，描述不必精确到构图细节，说清"有什么"即可。

## 3. 目标用户与场景

- 主要用户：公众号作者（本人），非专业设计师，不写复杂代码之外的需求。
- 核心场景：
  - **文生图**：写完一篇文章 → 打开本服务 → 选择风格/氛围等配置 → 简单描述主题 → 一键生成提示词 → 复制到即梦生图 → 插入文章。
  - **图生图**：手里已有（或已生成）一张图，但不满意或想复用 → 描述图片内容 + 想怎么改 → 生成图生图提示词 → 到即梦上传原图 + 粘贴提示词 → 得到修改后的图。典型如：图片放大、人像精修、横图扩成 2.35:1 首图、换风格做系列封面。

## 4. 核心流程

### 4.1 文生图流程

```
选择配置（可跳过，均有默认/不限定）
        │
        ▼
填写主题描述（可选，可留空）
        │
        ▼
点击「生成」→ Agent 处理：
  ① 解析主题意图，补全画面细节
  ② 将所有选项汇总为结构化提示词
  ③ 检查维度间冲突并修正（如情绪 vs 色调）
  ④ 按创意自由度要求做迭代润色
        │
        ▼
输出最终提示词（中文为主，后续支持双语）
        │
        ▼
一键复制 → 粘贴到即梦执行生图
```

### 4.2 图生图流程

```
选择场景（创意灵感 / 精准修改 / 风格转换）
        │
        ▼
描述图片内容（必填，说清"图片中有什么"即可）
        │
        ▼
按场景补充意向：
  · 创意灵感 → 选创意方向（可留空，默认全面发散）
  · 精准修改 → 填修改意向（可套用常用修改模板一键填充）
  · 风格转换 → 选目标风格（复用文生图的 18 种画面风格）
        │
        ▼
点击「生成」→ Agent 处理：
  ① 理解原图内容与主体
  ② 结合场景意图，明确"保持什么、改变什么"
  ③ 组装「原图参照 + 修改/创意指令 + 融合质量要求」结构
  ④ 冲突与质量检查（如修改意向与图片内容矛盾、扩图未指定画幅）
        │
        ▼
输出提示词（创意灵感输出一组 3 条，其余输出 1 条）
        │
        ▼
一键复制 → 到即梦上传原图 + 粘贴提示词执行图生图
```

#### 5.2 交互规则

- 单选维度：点击即选中，再点取消（回到"不限定"）。
- 用途场景联动：选择用途后自动设置推荐画幅，用户手动改画幅后以手动为准。
- 配置状态本地持久化（localStorage），刷新不丢失。
- 提供「预设模板」一键填充（见 M5）。

### M2 主题描述（P0）

- 多行文本输入，描述想表达的主题内容，如"一个年轻人在深夜的书房里写公众号文章"。
- **允许留空**：留空时仅基于选项生成氛围型提示词，并在结果中提示"补充主题可获得更精准结果"。

### M3 Agent 生成与优化（P0 原型为模拟，P1 接入真实 LLM）

点击「生成提示词」后，Agent 执行：

1. **意图解析**：理解主题描述的核心主体、动作、场景。
2. **细节补全**：根据创意自由度，补充合理的画面细节（未选择的维度由 Agent 按主题推断或留空）。
3. **冲突检查与修正**（示例规则，可持续扩充）：
   - 情绪「忧郁孤独/宁静平和」 + 色调「高饱和/霓虹撞色」 → 提示并调整为低饱和表述；
   - 用途与画幅不一致 → 自动按用途修正；
   - 负向「文字乱码」 + 文字「含标题文字」 → 在提示词中强调"文字清晰可读、无乱码"。
4. **汇总输出**：将所有维度组装为即梦友好的结构化中文提示词，形如：

```
电影感画面风格，主体：{主题描述}，背景为{背景环境}，{光线}，
{色调配色}，{构图}，{景别视角}，整体氛围{情绪}，呈现{质感}质感，
{文字留白要求}，超高细节，画质精致，画幅比例 16:9。
避免出现：水印、模糊低质量……
```

- 处理过程向用户展示分步状态（解析→补全→检查→输出），营造"迭代修复"的透明感。
- 结果区同时展示「优化说明」（Agent 做了哪些修正/补充）。

### M4 结果输出与复制（P0）

- 最终提示词以独立卡片展示，一键复制。
- 展示所选画幅比例，方便在即梦中对应设置。

### M5 预设模板（P0 提供 3 个内置，P2 开放自定义）

- 「公众号 · 科技感封面」：3D渲染 + 科幻冷感 + 霓虹撞色 + 留白放标题，2.35:1
- 「公众号 · 治愈插画」：手绘水彩 + 治愈温暖 + 黄金时刻暖调 + 留白，16:9
- 「公众号 · 写实摄影配图」：写实摄影 + 自然柔光 + 胶片复古 + 中景，3:2

### M6 历史与收藏（P1，本期不做）

- 生成历史列表、收藏常用配置为模板、提示词版本对比。

### M7 模式框架：文生图 / 图生图 Tab（P0）

- 顶部 Tab 切换两种模式，页面结构为「文生图 Tab + 图生图 Tab」。
- 两个 Tab 状态各自独立持久化（localStorage），切换、刷新均不丢失。
- 图生图模式复用整体布局（左侧配置、右侧生成与结果），降低学习成本。

### M8 图生图 · 场景系统（P0）

用户先选场景，场景决定后续需要填什么、Agent 怎么生成：

| # | 场景 | 输入 | 输出 | 说明 |
|---|------|------|------|------|
| 1 | 💡 创意灵感 | 图片内容描述 + 创意方向（可选） | **一组 3 条**创意提示词 | 基于现有图片发散创意：每个方向各出一条，可分别复制到即梦出图对比 |
| 2 | 🔧 精准修改 | 图片内容描述 + 修改意向 | 单条修改提示词 | 描述图片中有什么 + 希望怎么改；支持套用常用修改模板（M9） |
| 3 | 🎨 风格转换 | 图片内容描述 + 目标风格（可选） | 单条转换提示词 | 内容与构图不变，整体换视觉风格；风格选项**复用文生图的画面风格维度** |

- 创意方向（v0.2.1 扩充至 11 + 默认，均可不选）：
  - `系列延展`：同风格多图成套，适合连载封面
  - `换风格演绎`：同一内容换一种画风
  - `场景延伸`：主体不变，场景向四周/纵深/上方发散
  - `时光变换`：同一主体的不同季节、昼夜或年代
  - `视角再造`：换机位与景别（微距、俯瞰、第一人称……）
  - `情绪反转`：画面内容不变，情绪氛围转向对立面
  - `跨界混搭`：让主体闯入完全不相干的世界观
  - `拟人拟物`：物件拟人化，或主体变换物种形态
  - `故事续写`：想象画面的前一秒或后一刻
  - `细节放大`：让画面角落里的小物件成为主角
  - `极简海报`：提炼成海报级极简构图与大留白
  - `自由脑洞`（默认）：混合发散，每个方向各出一条
- 交互规则：图片内容描述**必填**（文生图主题可留空，图生图没有描述就没有参照）；切换场景时已填的描述保留；创意方向/目标风格可不选，由 Agent 自行判断。
- 修改意向（选填）**三个场景通用**：填写则生成时参考，留空由 Agent 自由发挥；常用修改模板（M9）仅精准修改场景提供，切换场景时清除已选模板。

### M9 图生图 · 常用修改模板（P0 内置 7 个，P2 开放自定义）

在「精准修改」场景下，点模板一键填充修改意向（可再手动编辑）。模板针对公众号作者高频需求：

| # | 模板 | 预填修改意向（摘要） | 典型用途 |
|---|------|----------------------|----------|
| 1 | 图片放大 | 高清放大、提升分辨率与细节锐度、修复噪点模糊，构图内容不变 | 小图变大图、截图变清晰 |
| 2 | 人像精修 | 自然磨皮、去除瑕疵、提亮眼神光，不改变相貌与构图 | 人物配图、出镜图优化 |
| 3 | 背景替换 | 将背景替换为指定场景，主体边缘自然融合、光影透视一致 | 主体不变换环境 |
| 4 | 去除杂物 | 移除路人、杂物、水印，背景自然延展补全 | 画面净化 |
| 5 | 换天气/季节 | 改变天气、时间或季节，色调光线同步调整，主体不变 | 氛围调整 |
| 6 | 老照片修复 | 去划痕污渍折痕、还原褪色色彩、提升清晰度，保留年代质感 | 修复类内容配图 |
| 7 | 扩图适配画幅 | 以原图为中心向外延展，适配目标画幅，延展部分风格无缝衔接 | 横图扩成 2.35:1 首图、竖图变横图（**与画幅比例联动**） |

### M10 图生图 · Agent 生成与优化（P0 原型为模拟，P1 接入真实 LLM）

1. **原图理解**：从描述中提取主体、场景、视角等要素。
2. **意图对齐**：明确"保持什么、改变什么"——图生图提示词的核心结构是**保持原图约束 + 修改指令**，与文生图的"从零描述"不同。
3. **组装输出**（精准修改示例）：
   ```
   参考原图：{图片内容描述}。修改要求：{修改意向}。
   保持原图的主体、构图与整体风格不变，仅执行上述修改，
   修改区域与原图光影、透视、色调自然融合，过渡无痕，画质保持高清。
   避免出现：修改痕迹明显、边缘锯齿、构图偏移。
   ```
4. **冲突与质量检查**（示例规则，可持续扩充）：
   - 修改意向与图片描述矛盾（如描述"一只猫"却选了人像精修模板）→ 提示确认；
   - 扩图模板未指定目标画幅 → 提示并按公众号首图 2.35:1 默认处理；
   - 人像精修但描述未提及人物 → 提示可能无人像可修。
5. **输出形态**：创意灵感场景输出 3 张提示词卡片，每条附一句"这条的方向是什么"的说明，**每张卡可独立复制**；其余场景单卡输出，与文生图结果卡一致，附优化说明。

## 6. 非功能需求

- **技术栈（P1 起）**：pnpm 管理依赖；React + Vite + TypeScript；组件库待定。
- **P0 原型**：单文件 HTML（原生 JS），无构建依赖，双击浏览器打开即可评审。
- **Agent 接入（P1）**：通过 LLM API 实现真实生成与迭代，需支持自定义 API Key；P0 用本地模板引擎模拟同等交互。
- **隐私**：全部配置仅存浏览器本地，不上传。

## 8. 开放问题

1. Agent 用哪家模型 API（豆包/方舟、OpenAI 兼容接口等），Key 如何管理？
2. 是否需要输出英文提示词（即梦中文优先，其他平台英文优先）？
3. 是否建立"出图反馈闭环"：用户标记某条提示词出图好坏，用于反哺 Agent 策略？
4. 风格等维度是否允许单维度多选（如同时叠"赛博朋克+蒸汽波"）？
5. 图生图 P3 是否支持直接上传原图、由多模态模型自动产出"图片内容描述"（省去手写描述）？

## 9. 验收标准（P0 原型）

- 全部 14 个维度可点选、可取消，用途联动画幅正确。
