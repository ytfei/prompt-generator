用户有一张图片，内容描述如下：

${desc}

请基于这张图发散创意。所选创意方向：「${direction}」（${direction_tip}）。

请在该方向上生成 3 条可直接用于即梦图生图的提示词，要求：
1. 3 条从${direction}的不同侧面/角度切入，各有差异，不要雷同；
2. 每条以「参考原图内容：{简述原图}」开头，明确这是基于已有图片的操作；
3. 说明保持什么（主体/构图/色调），改变什么，改变要贴合创意方向的含义；
4. 描述具体、有画面感，可直接执行；
5. 以「超高细节，画质精致」收尾。

关于修改意向：${modify_ref}

direction 为「自由脑洞」时，忽略上面的单方向要求，三个方向分别为：①系列延展（同风格多图成套）、②换风格演绎（同一内容换一种画风）、③场景延伸（主体不变、场景向外发散），每条对应一个方向，direction 字段填对应的方向名。

每条格式：direction 填方向名，note 用一句话说明这条的切入角度，prompt 为完整提示词。
